Akinsikun Tosin - Data Analyst Portfolio
=======================================
Contents
  index.html   the full website (HTML, CSS and JavaScript in one file)
  assets/      your uploaded photo

How to view it
  Double-click index.html. It opens in any browser.

How to put it online
  Upload this whole folder (keep index.html and assets/ together) to a static host
  such as Netlify Drop, GitHub Pages, Cloudflare Pages or Vercel.

How to edit the content
  Your text, projects, skills and links are stored in one block near the bottom of
  index.html: <script id="state" type="application/json">. Edit the values there.
  Put new images in assets/ and use paths like "assets/photo.jpg" where an image id
  is used (see the AX map in the script).

Note
  The Admin button, uploads and one-click publish only work on the Claude-hosted
  version. In this downloaded copy they stay hidden. The light/dark switch, project
  filter, contact form and everything else work as normal. Fonts load from Google
  Fonts, so an internet connection is needed to see them.
